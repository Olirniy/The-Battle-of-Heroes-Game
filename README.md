# The-Battle-of-Heroes-Game
# Гайд по игре "Битва героев" 🎮⚔️
# 📌 Основные правила
# Цель игры: победить героя компьютера, уменьшив его здоровье до 0.
- Игра пошаговая — ходы совершаются по очереди.
- В каждом раунде вы и компьютер атакуете друг друга.
- После победы можно продолжить с текущим героем или выбрать нового.

# 🕹️ Управление
- Выбор героя: вводите цифры (1, 2, 3) в консоль
- Подтверждение атаки: нажимайте Enter
# Продолжение игры:
- 1 — играть тем же героем
- 2 — выбрать нового героя
- Любая другая клавиша — выход
# 🦸‍♂️ Классы героев и их способности
### 1. Воин ⚔️
**Характеристики:**
- Здоровье: 110 ❤️
- Базовая атака: 25 💥
- Крит. шанс: 20% ⚡

**Уникальные способности:**
🔥 Берсеркерская ярость: 
Каждые 3 атаки воин впадает в ярость, 
увеличивая урон на 35% в следующем ударе!
### 2. Маг 🔮
**Характеристики:**
- Здоровье: 90 ❤️
- Базовая атака: 18 💫
- Крит. шанс: 15%

**Уникальные способности:**
✨ Магический дубль:
30% шанс атаковать дважды за ход!
### 3. Лучник 🏹
**Характеристики:**
- Здоровье: 100 ❤️  
- Базовая атака: 22 🎯  
- Крит. шанс: 25%  

**Уникальные способности:**
🎯 Уклонение:
25% шанс полностью избежать атаки противника!
## 🌟 Особенности игры
- У всех героев есть **шанс критического удара** (×1.5 урона)
- Компьютер выбирает героя **случайным образом**
- После каждого боя можно **сменить стратегию**, выбрав нового героя 
- или продолжить битву ранее выбранным героем.
